# 🚀 jQuery Advanced

> Master jQuery by building dynamic and interactive web applications.

---

## 🎯 Project Objective

**Learn jQuery from zero to expert** by building 3 real-world applications:

1. **Dynamic Interfaces** 🎨 - Create and manipulate HTML elements
2. **Wikipedia Search Engine** 🔍 - Connect to external APIs
3. **Post Manager** 📝 - Complete CRUD application

**Result**: You'll be able to create professional interactive web applications.

---

## 💡 Why This Project?

### What's the purpose?

This project teaches you **how websites actually work** behind the scenes. You'll understand:

- 🎨 **How to make pages interactive** - Buttons that do things, forms that respond
- 🔄 **How apps communicate with servers** - Loading data without refreshing the page
- 🛠️ **How to build real applications** - Not just static pages, but dynamic tools

### What will you gain?

**Practical skills for real jobs:**
- Build interactive websites and web applications
- Connect your frontend to any backend or API
- Understand how modern frameworks (React, Vue) work under the hood
- Debug and fix JavaScript issues confidently

### Real-world applications:

After this project, you can create:
- ✅ Search interfaces (like Google, Amazon)
- ✅ Social media feeds (post, delete, update)
- ✅ E-commerce product lists with filters
- ✅ Dashboard applications with real-time data
- ✅ Any web app that needs to talk to a server

**In short**: This project transforms you from someone who can make static pages into someone who can build interactive, professional web applications.

## 🚦 Quick Start

### For exercises 0-9
1. Open the HTML file in your browser
2. Press `F12` to open the console
3. Test the features

### For exercises 10-12
```bash
# 1. Install json-server
npm install json-server

# 2. Start the server
node_modules/.bin/json-server --watch db.json

# 3. Open the HTML file in your browser
```

---

## 💡 Tips

| Problem | Solution |
|---------|----------|
| jQuery doesn't load | Check your internet connection |
| Nothing displays | Open console (F12) and read errors |
| Server Error | Check that json-server is running |

**Important**: Follow exercises in order (0 → 12)!

## 📋 Overview

This project is part of the Web Front End specialization at Holberton School and focuses on learning and mastering the Bootstrap 4.4.1 CSS framework. It includes a series of progressive exercises that demonstrate the use of components, grid system, and interactive features of Bootstrap.

## 🎯 Project Objectives

This project aims to progressively learn the Bootstrap 4.4.1 framework through a series of practical exercises. Each HTML file represents a learning step that introduces new concepts:

- **Introduction** : Discovery of basic Bootstrap classes
- **Grid system** : Mastery of responsive design and columns
- **UI Components** : Navigation, tables, alerts and badges
- **Interactions** : Cards, modals and dynamic forms
- **Advanced navigation** : Tabs and collapsible content
- **Responsive design** : Conditional display utilities
- **Final project** : Complete professional pricing page

The objective is to understand how Bootstrap simplifies the development of modern and responsive web interfaces by learning to use its components, grid system, and integrated JavaScript features.

## 📚 General Concepts Learned

### Usage of Containers
- **Container** : `.container` for a responsive container with maximum width
- **Container Fluid** : `.container-fluid` for full screen width
- **Responsive** : Automatically adapts to different screen sizes

### Usage of the Grid system
- **12-column system** : Flexible division of horizontal space
- **Breakpoints** : `xs`, `sm`, `md`, `lg`, `xl` for different screens
- **Column classes** : `.col-*`, `.col-sm-*`, `.col-md-*`, etc.
- **Order and offset** : `.order-*`, `.offset-*` to control layout

### Usage of Components
- **Cards** : `.card`, `.card-header`, `.card-body` for structured content
- **Navigation** : `.navbar`, `.nav-tabs` for menus and tabs
- **Modals** : Interactive popup windows with JavaScript
- **Tables** : `.table`, `.table-dark`, `.table-hover` for tabular data
- **Buttons** : `.btn`, `.btn-primary` with different styles and sizes

### Usage of Utilities
- **Spacing** : `.p-*`, `.m-*` for padding and margin
- **Display** : `.d-block`, `.d-none`, `.d-flex` to control visibility
- **Flexbox** : `.d-flex`, `.justify-content-*`, `.align-items-*`
- **Colors** : `.text-*`, `.bg-*` for text and background colors
- **Responsive** : Conditional classes based on screen size

## 💻 Installation

```bash
# Clone the repository
git clone https://github.com/chacha-31/holbertonschool-web_front_end.git

# Navigate to the Bootstrap folder
cd holbertonschool-web_front_end/Bootstrap

# Open HTML files in a browser
# Or use a local server
python -m http.server 8000
```

## 🔗 Bootstrap CDN Usage

This project uses the CDN version of Bootstrap 4.4.1. To use it in your own projects, add this line in the `<head>` section of your HTML:

```html
<link rel="stylesheet" href="https://stackpath.bootstrapcdn.com/bootstrap/4.4.1/css/bootstrap.min.css" integrity="sha384-Vkoo8x4CGsO3+Hhxv8T/Q5PaXtkKtu6ug5TOeNV6gBiFeWPGFN9MuhOf23Q9Ifjh" crossorigin="anonymous">
```

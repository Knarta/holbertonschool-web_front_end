## 💻 Installation

### 1️⃣ Clone the repository

```bash
# Clone this repository
git clone https://github.com/chacha-31/holbertonschool-web_front_end.git

# Navigate to the directory
cd holbertonschool-web_front_end
```

### 2️⃣ Install dependencies

```bash
# Install Node.js dependencies
npm install
```

### 3️⃣ Launch the development environment

```bash
# Open with your favorite editor
code .

# Start the JSON server (if needed for JavaScript projects)
npx json-server --watch db.json --port 3000
```

## 🎮 Usage

### View projects

Most projects can be viewed directly by opening HTML files in your browser:

```bash
# Example: open an HTML project
open html_advanced/index.html  # macOS
xdg-open html_advanced/index.html  # Linux
start html_advanced/index.html  # Windows
```

### Compile Sass/SCSS

For projects using Sass:

```bash
# Install Sass globally (if not already done)
npm install -g sass

# Compile a Sass file
sass sass_scss/main.scss css/main.css

# Watch mode for automatic compilation
sass --watch sass_scss:css
```

### Local development server

For optimal development, use a local server:

```bash
# With Python 3
python3 -m http.server 8000

# With Node.js (http-server)
npx http-server -p 8000

# Then open http://localhost:8000 in your browser
```

## 📋 Overview

This repository contains my projects and exercises completed during the Web Front End specialization at Holberton School. It covers key modern front-end development concepts, focusing on HTML5, CSS3, JavaScript, responsive design, accessibility, and more.

## 🚀 Skills Covered

- HTML5 semantic markup
- CSS3 advanced styling and animations
- JavaScript fundamentals and DOM manipulation
- Responsive design principles
- Web accessibility implementation
- Modern CSS frameworks
- Front-end development best practices

## 📁 Project Structure

Each directory corresponds to a specific project or topic:

```
.
├── html_advanced/      # Advanced HTML concepts and semantic markup
├── CSS_advanced/       # Advanced CSS styling and techniques
└── W3C-Validator/      # Tools for validating HTML and CSS code
```

## 🎯 Learning Objectives

- Master HTML5 semantic elements and document structure
- Implement modern CSS layouts with Flexbox and Grid
- Create responsive designs that work across all device sizes
- Write clean, modular JavaScript code
- Ensure web accessibility compliance (WCAG)
- Use developer tools for debugging and optimization
